2. Кабинет продавца

То, чего нет в API по токену: список товаров с ценами и остатками, изменение цены, наличия и предзаказа.

Как в приложении Kaspi: номер владельца или сотрудника кабинета. Kaspi пришлёт код по SMS.

SMS не приходит? Вход через браузер
  1. На компьютере откройте kaspi.kz/mc в Chrome и войдите как обычно (с SMS-кодом).
  2. Нажмите F12 → вкладка Network → обновите страницу (F5).
  3. Выберите любой запрос к mc.shop.kaspi.kz → Headers → Request Headers.
  4. Скопируйте всё значение строки Cookie и вставьте ниже.

Cookie дают доступ к кабинету — вставляйте только сюда. Сервер хранит их зашифрованными, у вас в браузере.

Конкуренты на карточке

Номер карточки — из ссылки kaspi.kz/shop/p/…-123456789/ или из позиции заказа. Витрина Kaspi блокирует облачные серверы — работает, когда сервер запущен с обычного IP.

Демпинг — цена против конкурентов

Поставим цену на «шаг» ниже самого дешёвого конкурента, но не ниже вашего минимума (пола), чтобы не уйти в убыток. Меняет цену в кабинете, поэтому нужен вход в кабинет.

Сервер сам, по расписанию, держит цену ниже конкурентов (но не ниже пола) для товаров из списка.

Сообщения можно слать прямо в чат Kaspi, как сотрудник в кабинете — бесплатно. Kaspi не описывает этот чат, поэтому сначала находим его адрес по вашей сессии кабинета. Кнопка ничего покупателям не отправляет — только читает код кабинета.
