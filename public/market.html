Конкуренты на карточке

Номер карточки — из ссылки kaspi.kz/shop/p/…-123456789/ или из позиции заказа. Витрина Kaspi блокирует облачные серверы — работает, когда сервер запущен с обычного IP.

Подключение к NS WMS

NS WMS ходит в этот сервер так же, как за Kaspi QR. Адрес сервера — в переменной KASPI_BRIDGE_URL на стороне WMS. 


          
          

          
          
POST /api/market/connect          {token, merchantUid} → marketToken
POST /api/market/cabinet/login    {email, password}    → mcSession, merchants
GET  /api/market/capabilities

GET  /api/market/orders?state=NEW&days=14
GET  /api/market/orders/by-code/{code}
GET  /api/market/orders/{id}
POST /api/market/orders/{id}/accept
POST /api/market/orders/{id}/assemble   {numberOfSpace}
GET  /api/market/orders/{id}/waybill    → PDF

GET  /api/market/offers?q=&page=0&limit=50
POST /api/market/offers/update     {sku, price?, points?[{storeId, available, stockCount, preorder}]}
GET  /api/market/cards/{cardId}/competitors

Заголовки:
  X-Kaspi-Token + X-Merchant-Uid   — токен API как есть (или X-Market-Token из /connect)
  X-Mc-Session                      — сессия кабинета; сервер присылает обновлённую
                                      в ответном заголовке X-Mc-Session — сохраняйте её
