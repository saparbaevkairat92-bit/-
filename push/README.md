# Сервер «Копилки»

Один бесплатный сервер на Cloudflare Workers делает две вещи:

1. **Аккаунт и копия данных в облаке** — данные не теряются, восстанавливаются
   на любом устройстве, синхронизируются автоматически.
2. **Push-уведомления** — напоминания приходят, даже когда приложение закрыто.

## Что важно знать

- Сервер **не видит твои финансы**. Данные шифруются на телефоне (AES-GCM),
  ключ выводится из пароля и никогда не отправляется. На сервере лежит
  нечитаемый блок байтов.
- Пароль на сервер тоже не уходит: отправляется производный ключ, и от него
  хранится ещё один хэш.
- Уведомления идут пустым «сигналом» — текст собирает сам телефон из локальной
  базы (см. `sw.js`).
- Всё помещается в **бесплатный тариф** Cloudflare Workers.
- На iPhone push работает, только если приложение **добавлено на экран «Домой»**
  (iOS 16.4+). Открытое в обычной вкладке Safari — не получит.

## Установка (10 минут, один раз)

Нужен компьютер с Node.js — с телефона развернуть сервер не получится.

### 1. Аккаунт Cloudflare
Зарегистрируйся на https://dash.cloudflare.com — бесплатно, карта не нужна.

### 2. Ключи VAPID
В папке `push/`:

```bash
node genkeys.mjs
```

Скрипт выведет два ключа:
- **публичный** — вставь в `wrangler.toml` в поле `VAPID_PUBLIC_KEY`;
- **приватный** — это секрет, **не коммить его в репозиторий**.

### 3. Хранилище подписок

```bash
npx wrangler kv namespace create SUBS
```

Команда напечатает `id = "..."` — впиши его в `wrangler.toml` в секцию `[[kv_namespaces]]`.

### 4. Приватный ключ в секреты

```bash
npx wrangler secret put VAPID_PRIVATE_JWK
```

Вставь строку JSON с приватным ключом из шага 2 и нажми Enter.

### 5. Публикация

```bash
npx wrangler deploy
```

В конце получишь адрес вида `https://kopilka-push.<аккаунт>.workers.dev`.
Проверить: открой `<адрес>/health` — должно ответить `{"ok":true,"configured":true,...}`.

### 6. Подключение приложения

**Аккаунт:** «Копилка» → ⚙️ Настройки → **☁️ Аккаунт и копия в облаке** →
вставь адрес сервера → придумай логин и пароль → **«Создать аккаунт»**.
Дальше всё синхронизируется само.

**Уведомления:** ⚙️ Настройки → 🔔 Уведомления → **Push-уведомления** →
вставь публичный ключ → «Включить» → «Отправить проверочное».

Чтобы не вводить адрес на каждом устройстве, можно один раз прописать
его в файле `push-config.js` в корне репозитория (адрес и публичный ключ
публичные, их безопасно коммитить).

⚠️ **Пароль восстановить нельзя** — он и есть ключ шифрования. Если забудешь,
облачная копия не расшифруется. Данные на телефоне при этом останутся.

## Как работает синхронизация

- Копия отправляется автоматически через несколько секунд после изменения,
  при открытии приложения и при возврате из фона.
- Если пользоваться с двух устройств, данные **сливаются**, а не затираются:
  операции, копилки и челленджи объединяются по идентификаторам.
- Удаления не «воскресают»: приложение помнит удалённые записи полгода.
- При одновременной правке с двух устройств сервер отвечает конфликтом,
  приложение сливает данные заново и отправляет объединённый результат.

## Что хранится на сервере

| Ключ | Содержимое |
|---|---|
| `user:<логин>` | хэш ключа входа + зашифрованный блок данных + версия |
| `tok:<хэш>` | сессия (живёт 90 дней) |
| `sub:<id>` | подписка браузера на push |

Ничего из этого не позволяет прочитать финансы без твоего пароля.

## Расписание

По умолчанию — воскресенье 20:00 по Астане (`0 15 * * 0` в UTC).
Меняется в `wrangler.toml` в секции `[triggers]`.

Приложение само решает, что показать: если выписку не загружали неделю —
напомнит про выписку, иначе покажет итоги недели.

## Проверка вручную

```bash
# состояние сервера
curl https://<адрес>/health
```

## Стоимость

Бесплатный тариф Cloudflare Workers: 100 000 запросов в день и
1 крон-триггер. Для личного использования этого более чем достаточно.
